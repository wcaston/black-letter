# Know Your Shit

A passphrase-protected reference guide for a law school clinic's arraignment shifts.

**Open it:** https://wcaston.github.io/black-letter/

Everything in the guide is encrypted (`content.enc.json`). Nothing readable is stored in this repository, and the passphrase is shared only within the clinic.

## Put it on your phone

- **iPhone (Safari):** open the link, tap Share, then Add to Home Screen.
- **Android (Chrome):** open the link, tap the menu, then Install app (or Add to Home screen).

Open it once with a signal and enter the passphrase. After that it opens without a signal or the passphrase. Open it with a signal now and then to pick up updates.
